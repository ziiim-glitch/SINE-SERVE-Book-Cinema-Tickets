# SINE-SERVE-Book-Cinema-Tickets

SINE-SERVE is a Java-based console application designed to provide an advanced movie ticket and seat reservation system. It allows users to view currently showing and upcoming movies, select specific showtimes, choose preferred seating layouts, calculate billing breakdowns, and secure tickets seamlessly.

## Key Features
* **Movie Management:** View current movie line-ups, descriptions, schedules, and upcoming promos.
* **Ticket & Seat Reservation:** Enter ticket quantities and reserve specific seats dynamically.
* **Billing & Pricing:** Automatically compute sub-totals, discounts, and final amounts to pay.
* **Robust Exception Handling:** Validate user inputs and handle runtime exceptions smoothly to prevent crashes.

## Tech Stack
* **Language:** Java (Object-Oriented Programming)
* **Data Structures:** ArrayLists, Custom Collections, and 2D Arrays (for seating grids)
